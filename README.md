# 📄 ResumeMatch AI

### Intelligent Resume Screening & Job Recommendation System

ResumeMatch AI is an NLP-powered application that analyzes a candidate's resume, extracts relevant technical skills, identifies the candidate's strongest career domain, and recommends the most suitable job opportunities.

The system combines **skill matching** and **TF-IDF based semantic similarity** to calculate a hybrid resume-job compatibility score.

---

## 🚀 Features

- 📄 PDF resume upload
- 🔍 Automatic resume text extraction
- 🧹 Resume text preprocessing
- 🧠 Technical skill extraction
- 🎯 Career domain recommendation
- 💼 Top job recommendations
- 📊 Skill-match scoring
- 🔤 Semantic similarity using TF-IDF
- ⚡ Hybrid recommendation scoring
- 📚 Skill-gap analysis
- 📈 Job comparison visualization
- 📥 Downloadable recommendation results
- 🛡️ File-size and input validation
